# UFPR-ALPR Dataset

Este diretório é reservado para o dataset UFPR-ALPR.

O dataset é restrito para uso acadêmico e não pode ser redistribuído.

Envie um e-mail para rblsantos@inf.ufpr.br com o seguinte conteúdo:

**Assunto:** Application to download the UFPR-ALPR dataset.

```
Name: <seu nome completo>
Affiliation: <sua universidade>

E-mail: <e-mail institucional>
```
